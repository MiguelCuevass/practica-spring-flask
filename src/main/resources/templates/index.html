Sistema con Spring Boot y API Flask

Aplicación desarrollada para probar la integración entre un frontend con Thymeleaf, un backend con Spring Boot y una API externa implementada en Python con Flask.

El objetivo principal es simular distintos tipos de errores y comprobar cómo se gestionan desde la aplicación web.

Nota: para acceder a las pruebas es necesario iniciar sesión con un usuario almacenado en base de datos.
